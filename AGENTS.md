# AGENTS.md

This repository is Context Compass itself. Which guidance applies depends on
why the agent is here.

- Maintaining this repository (changing the payload, tools, tests, packaging,
  or these guides): read [contributor/AGENTS.md](contributor/AGENTS.md) next
  and follow that route.
- Using Context Compass in another project: start with
  [the Quickstart](README.md#quickstart). After installing, the agent follows
  `context_compass/AGENTS.MD` inside that project (`src/context_compass/`
  here is this repository's clean product source, not an installed copy).

Keep detailed repository-maintenance agent instructions in `contributor/`;
keep this root file as the entrypoint.
